# Contributing

Thank you for your interest in HOROOMART's design documentation.

## How to help

This repository documents a proprietary system, and its [licence](LICENSE) reserves all rights.
For that reason **we do not accept pull requests**. Contributors would have no right to modify the
material, and we cannot merge changes we have not written ourselves.

Your feedback is still genuinely useful. Please **open an issue** if you:

- find an **error or inconsistency**, such as a diagram that doesn't match the data dictionary, a
  broken link, or a statement that contradicts another document
- have a **question** about a design decision or how a part of the system works
- want to suggest a **topic** the documentation doesn't yet cover

Use the issue templates. They ask for the details we need to act on your report quickly.

## Before opening an issue

- Search existing issues first. Your point may already be raised.
- Point to the exact document and section (a link to the line is ideal).
- Keep each issue to one topic.

## Security problems

**Never report a security vulnerability in a public issue.** Follow [SECURITY.md](SECURITY.md)
instead.

## Conduct

Everyone taking part is expected to follow our [Code of Conduct](CODE_OF_CONDUCT.md).
